# Deep Learning-Based Detection, Coverage Estimation, and Temporal Growth Forecasting of Informal Settlements in Mumbai

## Overview
This project explores deep learning-based methods for detecting informal settlements, estimating their spatial coverage, and analysing temporal growth patterns in Mumbai using multi-temporal aerial imagery.

## Research Scope
- Aerial image preprocessing and quality control
- Image tiling and dataset preparation
- Settlement-region extraction and segmentation
- Spatial coverage and area estimation
- Multi-temporal change detection
- Temporal growth analysis and forecasting

## Repository Structure
- `notebooks/` – Research implementation and experiments
- `supplementary_material/` – Additional research documentation

## Supplementary Material
The supplementary document provides additional methodological details, experimental information, supporting figures and limitations associated with the research.
